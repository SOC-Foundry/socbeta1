# Firebase Analytics Setup for Flutter

This guide documents the steps to configure Firebase and integrate Firebase Analytics into a Flutter project.

## 1. Prerequisites

Ensure you have the following installed:
*   **Flutter SDK**: [Install Flutter](https://docs.flutter.dev/get-started/install)
*   **Firebase CLI**: [Install Firebase CLI](https://firebase.google.com/docs/cli)
    *   Run `firebase login` to authenticate.
*   **FlutterFire CLI**:
    ```bash
    dart pub global activate flutterfire_cli
    ```

## 2. Configure Firebase (FlutterFire)

Use the `flutterfire configure` command to connect your local Flutter project to your Firebase project. This command automatically generates the `lib/firebase_options.dart` file containing your API keys and project IDs.

1.  Run the configuration command in your project root:
    ```bash
    flutterfire configure
    ```
2.  Follow the interactive prompts:
    *   Select your Firebase project (or create a new one).
    *   Choose the platforms you want to support (Android, iOS, macOS, Web).
    *   The CLI will register your apps with Firebase and generate the configuration file.

## 3. Add Dependencies

Update your `pubspec.yaml` to include the necessary Firebase packages.

### Command Line
Run the following commands in your terminal:

```bash
flutter pub add firebase_core
flutter pub add firebase_analytics
```

### Manual `pubspec.yaml` Update
Alternatively, add the dependencies directly to your `pubspec.yaml` file:

```yaml
dependencies:
  flutter:
    sdk: flutter
  # Core Firebase package
  firebase_core: ^3.1.0 
  # Google Analytics for Firebase
  firebase_analytics: ^11.0.0 
```
*(Note: Check [pub.dev](https://pub.dev/packages/firebase_analytics) for the latest version numbers.)*

## 4. Initialize Firebase

Initialize Firebase in your `lib/main.dart` file before running the app.

```dart
import 'package:flutter/material.dart';
import 'package:firebase_core/firebase_core.dart';
import 'firebase_options.dart'; // Generated by flutterfire configure

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );

  runApp(const MyApp());
}
```

## 5. Track Screen Views (Router Configuration)

If you are using a router like `GoRouter`, you can automatically track screen views by adding a `FirebaseAnalyticsObserver`.

### `lib/router.dart`

```dart
import 'package:go_router/go_router.dart';
import 'package:firebase_analytics/firebase_analytics.dart';

final router = GoRouter(
  initialLocation: '/',
  observers: [
    // Add this observer to track navigation events
    FirebaseAnalyticsObserver(analytics: FirebaseAnalytics.instance),
  ],
  routes: [
    // Your routes here...
  ],
);
```

## 6. Verification

1.  Rebuild your application:
    ```bash
    flutter build web
    ```
    *(Or `flutter run` for mobile/desktop)*
2.  Deploy (if on web):
    ```bash
    firebase deploy
    ```
3.  Visit your app/website.
4.  Check the **Analytics > Realtime** dashboard in the Firebase Console. You should see user activity within minutes.
