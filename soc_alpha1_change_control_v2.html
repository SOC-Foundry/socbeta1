🚀 SOC Alpha1 - GCP Cloud-Native Architecture

Executive Summary

Closed-loop, agentic AI system that sits between a customer's SIEM and SOAR within their own org VPC. SOC Alpha1 learns from alert data to reduce noise and curate workflows before they enter the SOAR, using Google Cloud Platform's native services with Vertex AI for ML/AI capabilities. All data processing occurs within a private VPC ensuring zero data exfiltration to public internet.

🎯 System Purpose

Position: Between Customer SIEM (Panther) → SOC Alpha1 → Customer SOAR (Tines)

Function: Alert noise reduction, workflow curation, and intelligent classification through parallel AI agent analysis.

Output Routing: Medium, High, and Critical severity alerts flow to Tines SOAR for human action.

🚨 Critical Alert Triggers

  • Unauthorized AWS Changes: CloudTrail events with no correlated approved Jira change control ticket
  • Novel Anomalies: High anomaly score (>0.8) combined with zero historical pattern matches
Ingestion: Pub/Sub (Native)
Storage: BigQuery
ML/AI: Vertex AI
Compute: Cloud Run/Functions
Orchestration: Cloud Workflows
Security: Private Service Connect

End-to-end data flow from Panther SIEM through the four parallel AI agents to final classification and alerting. Panther publishes alerts directly to Pub/Sub via native integration. 2. Change Control Integration Workflow

Complete workflow from Jira change request through GitHub IaC pipeline to AWS deployment, CloudTrail logging, Panther detection, and SOC Alpha1 correlation. The Config Agent enriches CloudTrail-based alerts against the jira_change_tickets table — similar to how VirusTotal enriches DNS logs. Missing Jira correlation = Unauthorized Change = Critical Alert → Tines SOAR.

Change Control Enrichment Model

  • Enrichment Source: jira_change_tickets table in BigQuery (synced daily from Jira Cloud)
  • Correlation Keys: Resource ID, Principal, Timestamp Window, Change Ticket ID (if tagged)
  • Authorized Change: CloudTrail event correlates to APPROVED Jira ticket within change window
  • Unauthorized Change: CloudTrail event has NO correlated Jira ticket → CRITICAL → Tines SOAR

Severity Classification & Routing

  • CRITICAL: Unauthorized AWS changes (no Jira) OR Novel anomalies → Tines SOAR + Slack
  • HIGH: Known threat patterns with historical correlation → Tines SOAR
  • MEDIUM: Elevated risk requiring review → Tines SOAR
  • LOW/INFO: Authorized changes, expected behavior → BigQuery logging only
